# TechZone

**TechZone** — კომპიუტერული ტექნიკის ონლაინ მაღაზიის ერთგვერდიანი ვებინტერფეისის დემო-პროექტი. გვერდი აერთიანებს თანამედროვე, მუქ დიზაინს, პროდუქციის კატალოგს და მაღაზიის საკონტაქტო ინფორმაციას.

## პროექტის შესახებ

TechZone-ის მიზანია წარმოაჩინოს კომპიუტერული ტექნიკის ონლაინ მაღაზიის ვიზუალური მხარე. მომხმარებელს შეუძლია დაათვალიეროს პროდუქციის კატალოგი, გაეცნოს მაღაზიის უპირატესობებს და ნახოს საკონტაქტო ინფორმაცია.

ინტერფეისი ქართულ ენაზეა და იყენებს მუქ ფერთა პალიტრას, ბარათებზე დაფუძნებულ განლაგებასა და რესპონსიულ დიზაინს.

## ფუნქციები და სექციები

- **მთავარი გვერდი** — მისასალმებელი ტექსტი და მაღაზიის მოკლე პრეზენტაცია.
- **ჩვენ შესახებ** — მაღაზიის უპირატესობები: მიწოდება, გარანტია, მხარდაჭერა, ფასები, ორიგინალი პროდუქცია და გადახდის მეთოდები.
- **პროდუქტების კატალოგი** — ლეპტოპის, დესკტოპის, მონიტორის, პერიფერიული მოწყობილობებისა და კომპონენტების დემო-ბარათები.
- **კონტაქტი** — ტელეფონისა და ელფოსტის ბმულები.
- **ნავიგაცია** — გვერდის შესაბამის სექციებზე გადასასვლელი ბმულები.
- **რესპონსიული განლაგება** — Tailwind CSS-ის კლასებით მორგებული სხვადასხვა ეკრანის ზომაზე.

## გამოყენებული ტექნოლოგიები

| ტექნოლოგია | დანიშნულება |
|---|---|
| HTML5 | გვერდის სტრუქტურა და შინაარსი |
| Tailwind CSS v4 (Browser CDN) | სტილები და რესპონსიული განლაგება |
| Google Fonts — Inter | ტექსტის შრიფტი |
| SVG | ინტერფეისის ვექტორული აიქონები |

## გაშვება

პროექტის გასაშვებად:

1. ჩამოტვირთე ან დააკლონე Repository.
2. გახსენი პროექტის HTML ფაილი ბრაუზერში.
3. Tailwind CSS-ისა და Google Fonts-ის ჩასატვირთად საჭიროა ინტერნეტთან კავშირი.

თუ იყენებ Visual Studio Code-ს, შეგიძლია HTML ფაილი გახსნა Live Server გაფართოებით.

## პროექტის სტრუქტურა

ამჟამად მოწოდებული კოდის მიხედვით პროექტის ძირითადი ნაწილი ერთ HTML ფაილშია მოთავსებული. თუ მომავალში CSS ან JavaScript ცალკე ფაილებად გამოიყოფა, სტრუქტურა შესაბამისად განაახლე.

## მნიშვნელოვანი შენიშვნა

ეს ვერსია წარმოადგენს **frontend დემო-ინტერფეისს**. მოწოდებულ HTML კოდში არ ჩანს backend, მონაცემთა ბაზა, მომხმარებლის ავტორიზაცია ან რეალური შეკვეთის/გადახდის სისტემა. კალათისა და პროდუქტის მოქმედების ზოგიერთი ბმული ჯერ მხოლოდ ვიზუალურია (`#`).

ასევე, გვერდზე ნაჩვენები პროდუქტები, ფასები, სტატისტიკა და საკონტაქტო მონაცემები კოდში მითითებული დემო-ინფორმაციაა. რეალურ გამოყენებამდე გადაამოწმე და შეცვალე ისინი შესაბამისი მონაცემებით.

## მომავალი გაუმჯობესებები

- პროდუქტის დეტალური გვერდების დამატება;
- კალათისა და შეკვეთის ფუნქციონალის რეალიზება;
- საძიებო და კატეგორიების ფილტრაციის დამატება;
- backend-ისა და მონაცემთა ბაზის დაკავშირება;
- საკონტაქტო ფორმის დამატება.
